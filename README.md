# Python Mini Projects

A collection of beginner-friendly Python projects built while learning Python programming.

## Projects Included

### 1. Snake Water Gun Game

A simple command-line game where the user plays Snake, Water, and Gun against the computer.

#### Concepts Used

* Conditional Statements
* Random Module
* User Input
* Functions
* Game Logic

---

### 2. Number Guessing Game

A simple Python game where the user tries to guess the correct number generated by the computer.

#### Concepts Used

* Loops
* Conditional Statements
* Random Module
* User Input

---

### 3. Rent Calculator

A basic Python application used to calculate and split house rent expenses among roommates.

#### Concepts Used

* Arithmetic Operations
* User Input
* Variables
* Calculations
* Functions

---

### 4. UPI QR Code Generator

A Python project that generates UPI payment QR codes for PhonePe, Paytm, and Google Pay using a UPI ID.

#### Concepts Used

* QR Code Generation
* String Formatting
* User Input
* File Handling
* External Libraries (`qrcode`, `Pillow`)

#### Features

* Generates QR codes for multiple payment apps
* Saves QR codes as PNG image files
* Displays generated QR codes automatically

---

## Technologies Used

* Python
* qrcode Library
* Pillow (PIL)

This repository documents my Python learning journey through mini projects and practice applications.
